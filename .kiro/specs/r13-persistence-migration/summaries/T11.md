  - Body cap: FastAPI reads a declared body before any dependency runs, so the three write endpoints no longer declare a body model. A dependency checks `Content-Length` first, then counts bytes while streaming (covers chunked bodies), and gives 413. The endpoint then validates the bytes itself and raises `RequestValidationError`, so 422s keep FastAPI's shape (`loc` starts with `body`). Side effect: OpenAPI no longer shows the request schemas for these three endpoints.
  - Storage caps on create and import, checked only for an id that does not exist yet (an existing id is either the caller's own row, replaced in place, or a foreign one that gives 409/skipped). 422 with a message. On import, a cap stops the run with 422 and the projects written before it stay written (each project has its own transaction). F4 already treats a 422 as "do not retry in this run".
