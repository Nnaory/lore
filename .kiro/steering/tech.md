# Stack, perintah, env, test

- **Frontend (`frontend/`):** Next 16.4.5 (App Router, `cacheComponents`, `reactCompiler`, Turbopack dengan loader Tailwind), React 19.3, TypeScript strict, Tailwind 4, Zod 3, `@remotion/player` 4.0.543, pdfjs-dist, mammoth, jszip, lucide-react, font `Space Grotesk` (`--font-display`) dan `JetBrains Mono` (`--font-mono`) lewat `next/font/google` (`src/app/fonts.ts`), serta generator/komponen ASCII Kit di `src/lib/ascii` dan `src/components/ascii`. Runtime Node 26 (`.nvmrc`).
  - Test: Vitest 3, Testing Library, jsdom, fake-indexeddb, fast-check.
  - Fitur animasi menambah devDependency `esbuild` 0.28.2 (dipin; membangun runtime sandbox) dan, direncanakan, `@fontsource/space-grotesk` dan `@fontsource/jetbrains-mono` (font disematkan sebagai `data:` URI di sandbox karena CSP `font-src data:`). **Paket `@fontsource/*` belum terpasang**: `predev` dan `prebuild` (`node scripts/build-sandbox.mjs`) berhenti dengan kode 1 (disengaja) sampai operator menjalankan `cd frontend && npm install --save-dev --save-exact @fontsource/space-grotesk @fontsource/jetbrains-mono esbuild@0.28.2` dan meng-commit `package.json` dan `package-lock.json`. Selama itu `npm run dev`, `npm run build`, `ci/web`, dan build Docker web tidak jalan.
  - Dependensi baru wajib dipin persis (tanpa `^`, `~`, `>=`, `*`, `latest`; `==` di Python). Dijaga `frontend/tests/animation/reuse-guards.test.ts`, `backend/tests/test_animation_reuse.py`, dan `scripts/ci/check-animation-versions.py` (`react`, `react-dom`, `remotion`, `@remotion/player` harus sama di frontend dan verifier).
  - Alias `@/*` → `src/*` (di dalam `frontend/`).
  - Perintah (jalankan dari `frontend/`): `npm run dev | build | lint | test | test:watch | test:coverage`. `dev` dan `build` didahului `node scripts/build-sandbox.mjs` (hook `predev`/`prebuild`) yang menulis `public/sandbox/runtime.{html,js}`.
  - Next 16 punya breaking changes: baca `node_modules/next/dist/docs/` (resolve dari root repo; lihat `AGENTS.md`) sebelum menulis kode Next.
  - `frontend/node_modules` tidak selalu ada di mesin lokal (kadang hanya `node_modules` di root). Jalankan `npm ci` di `frontend/` sebelum lint, tsc, atau vitest.
  - Urutan check CI web (dari `.github/workflows/ci.yml`): `npm run lint`, `npx next typegen`, `npx tsc --noEmit`, `npx vitest run --testTimeout=60000`, `npm run build` (tanpa env AI; web tidak memanggil AI). `npm run build` kini menjalankan `prebuild` (sandbox) lebih dulu.
- **Verifier animasi (`animation-verifier/`):** Node 22 (`.nvmrc`), TypeScript 5.9.3, ESLint 9.39.5 dengan `typescript-eslint` 8.72.1, esbuild 0.28.2, jsdom 26.1.0, React dan React DOM 19.3.0, `remotion` dan `@remotion/player` 4.0.543, Zod 3.25.28; dev: Vitest 3.2.3, fast-check 4.10.3, `@types/node` 22.20.1. Semua dipin persis; `package-lock.json` belum ada (lihat bawah). Image Lambda: `public.ecr.aws/lambda/nodejs:22`, `linux/amd64`, tanpa provenance dan SBOM.
  - Perintah (dari `animation-verifier/`): `npm run lint` (`eslint -c eslint.package.config.mjs --max-warnings 0 .`), `npx tsc --noEmit`, `npm run typecheck`, `npm test` (`vitest run`, termasuk korpus `fixtures/{good,bad,warn}` yang menulis `.corpus-results.json`), `npm run build`. Di mesin dengan RAM sempit jalankan Vitest dengan `--maxWorkers=2 --minWorkers=1`. Kasus memori 1,4 GB aktif sendiri bila memori bebas minimal 3 GiB (`LORE_VERIFIER_HEAVY=1 npx vitest run tests/render-real.test.ts -t "1,4 GB" --testTimeout=60000`).
  - Urutan check CI `ci/verifier` (job `verifier`): `npm ci`, `npm run lint`, `npx tsc --noEmit`, `npm run typecheck`, `npx vitest run`, `shellcheck scripts/ci/*.sh`, build image `lore-verifier:ci`, lalu `scripts/ci/verifier-rie-check.sh lore-verifier:ci animation-verifier` (membaca `.corpus-results.json`, jadi Vitest harus lebih dulu di job yang sama). `ci/contracts` (job `contracts`, Python 3.12, pustaka standar): `python3 scripts/sync-animation-contract.py --check`, lalu `python3 scripts/ci/check-animation-versions.py`. Keduanya merah sampai `animation-verifier/package-lock.json` ada (`cd animation-verifier && npm install --save-exact`, dijalankan online lalu commit; jangan ditulis tangan).
- **Backend (`backend/`):** Python 3.12, FastAPI 0.163.2, Uvicorn 0.54.0, SQLAlchemy 2.1.9, psycopg[binary] 3.3.9, Alembic 1.20.1, httpx2 2.16.2, Ruff 0.17.5, Pytest 9.2.0, serta untuk fitur animasi `langgraph==1.2.24` dan `boto3==1.44.13` (dipin dari metadata PyPI; instalasi dan tes dengan paket asli belum dijalankan: `cd backend && pip install -r requirements.txt -r requirements-dev.txt && pytest -q -rs`).
  - Perintah (jalankan dari `backend/`): `ruff check . && ruff format --check .`, `alembic upgrade head`, `pytest -q` (yang dipakai CI; `-v` boleh untuk lokal).
  - Ruff: `line-length = 100`, aturan `E,F,I,B,UP` (`backend/pyproject.toml`).
- **Env frontend (`frontend/.env.example`):** `NEXT_PUBLIC_PROJECT_STORE` (`idb` | `http`), `NEXT_PUBLIC_ANIMATIONS` (Flag_Web, `on` | `off`, default `off`; dibaca saat build dan di-inline, hanya nilai persis `on` yang menyalakan; `on` hanya setelah daftar periksa browser, smoke, pengukuran memori, dan estimasi biaya selesai; build arg di `frontend/Dockerfile` dan `release-web.yml` dari variabel repositori `NEXT_PUBLIC_ANIMATIONS`), dan opsional `LORE_API_ORIGIN` (target rewrite `/api/v1/*` saat `npm run dev`, default `http://localhost:8000`). Web tidak memegang key AI.
- **Env backend:** `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, `PGPASSWORD`, `PGSSLMODE` (default `require`), `DB_POOL_SIZE` (default 5), `DB_MAX_OVERFLOW` (default 5, maks 10 koneksi per proses), `DB_CONNECT_TIMEOUT` (default 5), serta AI:
  - `AI_PROVIDER=google` (satu-satunya provider; tidak ada provider offline/dummy di runtime);
  - `GOOGLE_API_KEY` (atau `GEMINI_API_KEY`); tanpa key (atau placeholder `__SET_ME__`), endpoint AI mengembalikan `PROVIDER_NOT_CONFIGURED` dan UI menampilkan peringatan;
  - `AI_MODEL`: daftar model dipisah koma, dicoba berurutan (default `gemini-3.5-flash-lite`);
  - `AI_TIMEOUT_MS=300000` per request dan `AI_DEADLINE_MS=300000` total per langkah (default di `app/ai/settings.py`);
  - batas: `AI_RATE_PER_MINUTE_IP`, `AI_RATE_PER_MINUTE_OWNER`, `AI_DAILY_PER_IP`, `AI_MAX_CONCURRENT_PER_IP`, `AI_MAX_CONCURRENT_GLOBAL` (`app/ai/limits.py`);
  - animasi (`app/ai/animation/limits.py`, `app/ai/settings.py`; semua diisi Terraform lewat SSM, lihat steering `backend` dan `docs/infra/12-remotion-animation.md`): `ANIMATION_ENABLED` (Flag_Api, default `false`), `ANIMATION_BUCKET`, `ANIMATION_VERIFIER_FUNCTION`, `AWS_REGION`, `ANIMATION_RATE_PER_MINUTE_IP=4`, `ANIMATION_DAILY_PER_IP=30`, `ANIMATION_MAX_CONCURRENT_PER_IP=1`, `ANIMATION_MAX_CONCURRENT_GLOBAL=2`, `ANIMATION_MAX_ATTEMPTS=4`, `ANIMATION_DEADLINE_MS=240000`, dan opsional `AI_ANIMATION_MODEL` (jatuh ke `AI_MODEL`, lalu default). Verifier_Lambda tidak punya env sama sekali.
- Jangan pernah menaruh API key atau password di kode atau di steering ini. Pakai `.env`.

## Test
- **Frontend:** Vitest di `frontend/tests/` (dijalankan dengan Zod 3). Dikelompokkan per domain: contracts, story, schemas, ingest, campaign, knowledge, setup, stage, game, generation, state, api health, ascii, cast, dialogue, home, ui, lib, animation. Fixture di `frontend/tests/fixtures/`; `backend-fetch.ts` melayani fixture AI backend.
- Environment default `node`. File yang butuh DOM memakai docblock `@vitest-environment jsdom`.
- `frontend/tests/setup.ts` memuat jest-dom dan `fake-indexeddb/auto`, menambah polyfill `Blob.text/arrayBuffer`, dan memperbaiki localStorage di Node 25.
- **Backend:** `backend/tests/` (suite AI dan animasi berjalan tanpa Postgres atau jaringan; tes DB, termasuk 30 dari 32 tes `test_animation_migration.py`, memakai service container `postgres:16-alpine` di CI dengan `alembic upgrade head` + `pytest`, dan di-skip tanpa `PGHOST`).
- **Verifier:** Vitest di `animation-verifier/tests/` dengan korpus `fixtures/{good,bad,warn}` (8 good lulus, 34 bad dengan kode yang diharapkan, 3 warn).
- **Infra checkers:** `scripts/ci/test-checkers.py` (200 tes `unittest` pada pelaksanaan R14, termasuk fixture checker animasi dan `scripts/verify/test_animation_smoke.py`) + `check-cost-static`.
- Status lokal saat rilis terbaru (sebelum R14): lint web 0 error / 0 warning, `tsc --noEmit`, `npm run build`, Vitest & golden parity 40/40 lulus, ruff clean, Pytest AI lulus. Terraform divalidasi di CI `ci/terraform`. Untuk R14 banyak verifikasi masih `[belum diverifikasi]` (Postgres, `langgraph`/`boto3` asli, image Docker, browser, Terraform plan nyata): daftarnya di `docs/infra/12-remotion-animation.md` dan steering `known-issues`.
