# Backend (FastAPI)

- Python 3.12, FastAPI, SQLAlchemy 2.1, psycopg 3, Alembic, Ruff, Pytest. Perintah dari `backend/`: `ruff check . && ruff format --check .`, `alembic upgrade head`, `pytest -q` (CI).
- Gaya Python: ruff `E,F,I,B,UP`, `line-length = 100`. Tiap modul diawali docstring tujuan dan alasan, dan memakai `from __future__ import annotations`. Skrip CLI memakai `def main() -> int` (atau `main(argv)` bila menerima argumen, seperti `scripts/sync-animation-contract.py`) dan `raise SystemExit(main())`.
- Endpoint probe (health) mengirim `Cache-Control: no-store` (`app/main.py`).
- Migrasi Alembic ditulis tangan (`target_metadata = None`). Revisi yang ada: `4ee36ac0a0f8` (kosong), `7c1d9e4a52b8` (tabel project R13), dan `725515cc1581` (tabel `animations`, `down_revision` `7c1d9e4a52b8`); jangan edit revisi yang sudah ada, tambah revisi baru. Migrasi dijalankan otomatis saat deploy (`deploy/common/deploy.sh`, service `migrate`), jadi harus expand-only dan backward-compatible.
- Modul: `app/main.py` (factory, middleware, router), `app/db.py`, `app/owner.py` (cookie `lore_device` untuk `/api/v1/projects`, `/api/v1/ai`, dan `/api/v1/animations`), `app/models.py` (envelope Pydantic), `app/ratelimit.py`, `app/projects.py` (router dan batas), `app/ai/` (pipeline AI; detail di steering `ai-pipeline`), dan `app/ai/animation/` (fitur animasi R14). Detail persistensi di steering `persistence`.
- Modul `app/ai/animation/`: `contract.py` (+ salinan `animation-contract.json`), `models.py`, `tokens.py`, `prompts.py`, `limits.py`, `agent.py` (LangGraph), `verifier_client.py` (`boto3` Lambda), `store.py` (S3), `registry.py` (SQL `animations`), `sse.py`, `endpoint.py` (POST, Reader, fragmen health), `logging_.py`, `logconfig.py`. `main.py` membuat `app.state.animation_limiter`, `animation_limits`, dan `animation_runtime` (`None` sampai request pertama yang lolos pemeriksaan konfigurasi), serta memasang handler log INFO `lore.animation` di lifespan, bukan saat impor.
- Endpoint: `GET /health` (liveness), `GET /health/db` (readiness `SELECT 1`), `GET /health/ai` (`{"configured": bool, "animation": {"enabled": bool, "configured": bool}}`: key Gemini terpasang, flag animasi, dan kelengkapan konfigurasi animasi; hanya membaca env, tidak memanggil Gemini atau AWS), `GET /api/v1/health` (health publik lewat Caddy), `/api/v1/projects` (list, create, get, delete, `PUT /{id}/state`, `POST /import`), `POST /api/v1/ai/{analyze-material,plan-campaign,generate-story}`, `POST /api/v1/ai/animations` (SSE), dan Reader `GET /api/v1/animations/{animation_id}` (satu segmen; URL presigned S3 300 detik, hanya untuk Owner, 404 identik bila id tidak ada atau milik orang lain, `RegistryError`/`StoreError` jadi 503 `ANIMATION_STORAGE_FAILED`, lainnya 500 `UNKNOWN`). Dengan Flag_Api `false`, POST dan Reader menjawab 503 `ANIMATION_NOT_CONFIGURED` tanpa menyentuh AWS.
- Env: `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, `PGPASSWORD`, `PGSSLMODE` (default `require`; Postgres lokal tanpa TLS butuh `disable`), `DB_POOL_SIZE` (default 5), `DB_MAX_OVERFLOW` (default 5, maks 10 koneksi per proses), `DB_CONNECT_TIMEOUT` (default 5), `AI_PROVIDER=google`, `AI_MODEL`, `AI_TIMEOUT_MS`, `AI_DEADLINE_MS`, `AI_RATE_*`/`AI_DAILY_PER_IP`/`AI_MAX_CONCURRENT_*`, `GOOGLE_API_KEY` (production: SSM SecureString, diisi manual; runbook 3.2a).
- Env animasi (diisi Terraform lewat SSM `/lore/prod/api/env/*`, dirender saat deploy api): `ANIMATION_ENABLED` (Flag_Api, default `false`, hanya teks `true`), `ANIMATION_BUCKET`, `ANIMATION_VERIFIER_FUNCTION`, `AWS_REGION` (wajib: `boto3` membaca `AWS_DEFAULT_REGION`, jadi `region_name` selalu diberikan eksplisit), `ANIMATION_RATE_PER_MINUTE_IP` (4), `ANIMATION_DAILY_PER_IP` (30), `ANIMATION_MAX_CONCURRENT_PER_IP` (1), `ANIMATION_MAX_CONCURRENT_GLOBAL` (2), `ANIMATION_MAX_ATTEMPTS` (4, jepit 1 sampai 4), `ANIMATION_DEADLINE_MS` (240000, jepit 1 sampai 240000), dan opsional `AI_ANIMATION_MODEL` (daftar model dipisah koma, tidak dibuat Terraform). Parser angka hanya menerima string digit ASCII bernilai 1 atau lebih; ini sengaja bukan `_positive_int` dari `limits.py`. Flag, bucket, nama fungsi, region, `ANIMATION_MAX_ATTEMPTS`, dan `ANIMATION_DEADLINE_MS` dibaca per request; empat batas limiter dibaca sekali saat proses start.
- Dependensi animasi dipin persis di `requirements.txt`: `langgraph==1.2.24`, `boto3==1.44.13`. Keduanya hanya boleh diimpor secara tertunda (di dalam `build_graph()` dan fabrik klien); dengan Flag_Api `false`, impor `app.main`, `/health/ai`, POST, dan Reader tidak memuat `langgraph`, `boto3`, atau `botocore` (dijaga `test_animation_memory.py`). Level logger `botocore`/`boto3` dipaksa `WARNING` saat runtime animasi dibuat.
- Test butuh Postgres 16 (CI memakai service container `postgres:16-alpine`; DB `lore`, user `lore_test`). Test DB di-skip tanpa `PGHOST`; test AI tidak butuh Postgres maupun jaringan. Fixture DB bersama ada di `tests/conftest.py`; `tests/fixtures/project.json`, `tests/fixtures/ai/*.json`, dan `tests/fixtures/animation/*` juga dipakai contract test frontend.
- Test animasi: `tests/test_animation_*.py` dengan pendukung `tests/animation_*_support.py` dan `tests/fake_s3.py` (S3, Lambda, Gemini, dan registry palsu; tanpa jaringan). Tes yang butuh paket asli (`test_real_langgraph_matches_the_driver`, `test_real_botocore_*`, RSS di `test_animation_memory.py`) di-skip tanpa `langgraph`/`boto3` terpasang dan aktif sendiri bila ada. 30 dari 32 tes `test_animation_migration.py` butuh Postgres. Satu tes lama gagal hanya di mesin tanpa DNS: `test_ai_gemini_client.py::test_key_that_is_not_a_valid_header_is_fatal_and_not_echoed`.
- Kontrak animasi: `app/ai/animation/animation-contract.json` adalah salinan, bukan sumber. Ubah `animation-verifier/contract/animation-contract.json` lalu jalankan `python3 scripts/sync-animation-contract.py` (`--check` di CI).
- HTTP client: `httpx2` (lanjutan httpx yang dirawat Pydantic), di `requirements.txt`.
- Jalankan lint dengan `ruff check . --no-cache` sebelum commit: cache ruff pernah menyembunyikan urutan import yang salah.
- Pipeline AI port 1:1 dari Next.js berjalan di `app/ai/` dengan request/response JSON biasa. Pengecualian: fitur animasi memakai LangGraph dan SSE (`app/ai/animation/`), mati secara default. Fitur v2 lain (AI grilling, credit simulation, `/api/chat/in-character`) belum ada.
