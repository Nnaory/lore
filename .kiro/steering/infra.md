# Infra dan CI/CD

- Infrastruktur AWS (`ap-southeast-3`) dikelola via `infra/` + `.github/workflows/{ci.yml,infra.yml,release-web.yml,release-api.yml,release-verifier.yml}`: VPC `10.20.0.0/16`, NAT instance `t3.micro`, `web` (`t3.micro`, Caddy + Next.js), `api` (`t3.micro`, FastAPI private subnet), dan RDS PostgreSQL 16 (`db.t3.micro`, 20 GB `gp3`, `backup_retention_period = 1`). Fitur animasi (R14) menambah bucket S3, repositori ECR, fungsi Lambda verifier, dan beberapa resource pendukung (bagian "Animasi Remotion").
- Deploy aplikasi memakai OIDC + AWS SSM (`scripts/ci/ssm-deploy.sh`, `/opt/lore/{render-env.sh,deploy.sh,compose.yml}`), GHCR publik (`ghcr.io/nnaory/lore-{web,api}:sha-*`). Dependabot sengaja tidak digunakan.
- Dokumentasi arsitektur yang sudah diimplementasikan (R1–R13): `docs/infra/`. R14 (animasi) ada di `docs/infra/12-remotion-animation.md`: kodenya sudah ditulis tetapi belum dirilis dan belum dinyalakan.
- Ada guardrail biaya (`scripts/ci/test-checkers.py`, `check-cost-static`). Jangan menaikkan ukuran instance, IOPS, atau retensi backup tanpa persetujuan pengguna, karena memakai free plan.
- **`terraform apply` dijalankan otomatis oleh CI** (`infra.yml`, environment `production`) saat push ke `main` bila ada perubahan, dengan guard: plan yang menghapus `aws_db_instance`, `aws_eip`, atau `aws_s3_bucket` diblokir kecuali `workflow_dispatch` dengan `allow_destroy`. Karena itu perubahan `infra/**` harus lewat PR dan check CI.
- Agent TIDAK boleh menjalankan `terraform apply/destroy` atau perintah AWS yang mengubah resource dari mesin lokal (hook `guard-shell` memblokirnya). Verifikasi lokal yang aman: `terraform -chdir=infra fmt -check -recursive`, `init -backend=false`, `validate`, `python3 -B scripts/ci/check-cost-static infra`, `python3 -B scripts/ci/test-checkers.py -v`, `shellcheck`.
- Ada dua compose terpisah: `deploy/web/compose.yml` (Caddy + Next.js) dan `deploy/api/compose.yml` (FastAPI, profil `migrate`). Caddy dikonfigurasi di `deploy/web/Caddyfile`.
- `infra/backend.tf` memuat nama bucket tfstate yang berisi ID akun AWS. Jangan menyalinnya ke steering, hook, atau dokumen publik. Tulis id akun sebagai `<ACCOUNT_ID>`; nama bucket animasi ditulis `lore-prod-animations-<ACCOUNT_ID>`. Dokumen 12 dan seluruh `.kiro/steering/*.md` tidak boleh memuat id akun 12 digit, parameter tanda tangan URL presigned, atau pola kunci akses AWS (dipindai `backend/tests/test_animation_docs.py`, jadi pola itu sendiri tidak ditulis di sini).
- Gaya bash: `set -euo pipefail` dan helper `fail()` (contoh: `scripts/ci/ssm-deploy.sh`, `scripts/verify/network.sh`).
- Pola mengubah infra dengan guardrail biaya: `infra/*.tf` → `scripts/ci/policy_rules.py` (allowlist/denylist) → `scripts/ci/check-cost` dan `check-tags` → fixture di `scripts/ci/fixtures/` → `scripts/ci/test-checkers.py`.

## Animasi Remotion (R14)
Sumber: `.kiro/specs/ai-remotion-animation/`; operasi dan runbook: `docs/infra/12-remotion-animation.md`.

**Resource baru** (`infra/animation.tf`, semuanya `Component = "animation"`, kecuali parameter SSM yang `Component = "api"`):
- S3 `lore-prod-animations-<ACCOUNT_ID>`: privat, Block Public Access penuh, SSE, TLS wajib lewat policy, CORS satu aturan `GET` tanpa `*`, lifecycle hanya abort multipart 7 hari, `force_destroy = false`.
- ECR `lore-prod-animation-verifier` (tag `IMMUTABLE`, scan on push, menyimpan 5 image), log group `/aws/lambda/lore-prod-animation-verifier` (retensi 7 hari, satu-satunya log group yang diizinkan guardrail), security group tanpa rule, role eksekusi minimal, dan fungsi Lambda `lore-prod-animation-verifier` (container image, 1536 MB, 60 detik, subnet data, tanpa egress, tanpa env, tanpa reserved concurrency).
- Policy `api_animation` pada role `lore-prod-api-instance`: `s3:PutObject`/`GetObject` hanya prefix `animations/*`, `s3:ListBucket` dengan kondisi prefix, dan `lambda:InvokeFunction` pada satu ARN.
- Sepuluh parameter SSM `/lore/prod/api/env/*` (sembilan di `animation_ssm_params`, satu `ANIMATION_ENABLED` terpisah dengan `precondition` bahwa tag image terisi).
- `aws_instance.api` `metadata_options.http_put_response_hop_limit = 2` (hanya `api`; `web` dan `nat` tetap 1) supaya `boto3` di container Docker bisa mengambil kredensial IMDSv2. IMDSv2 tetap wajib. Jangan menulis `hop limit 1` tanpa menyebut `web` atau `nat` di dokumen.
- Variabel (`infra/variables.tf`, diubah lewat PR): `animation_enabled` (default `false`), `animation_verifier_image_tag` (kosong atau `sha-xxxxxxx`), `animation_cors_extra_origins`. Lambda dibuat hanya bila tag terisi (dua kali apply), `image_uri` di-`ignore_changes`.
- `deploy/**` tidak berubah (mengubahnya mengganti instance). Caddy sudah memakai `flush_interval -1` untuk `/api/v1/*`, jadi SSE tidak butuh perubahan.

**Aturan guard** (`scripts/ci/policy_rules.py`, `check-cost`, `check-cost-static`, `check-tags`): `animation` ada di `ALLOWED_COMPONENTS`. Lambda ditolak bila memori di atas 1536 MB, timeout di atas 60 detik, `package_type` bukan `Image`, atau reserved concurrency di atas 0; `aws_lambda_provisioned_concurrency_config`, `aws_lambda_function_url`, dan `aws_apigatewayv2_api` ada di denylist. ECR wajib scan dan tag immutable, bucket wajib Block Public Access penuh dan tanpa `aws_s3_bucket_acl`. `aws_cloudwatch_log_group` tetap di denylist dengan satu pengecualian bernama (`aws_cloudwatch_log_group.animation_verifier`, nama `/aws/lambda/lore-prod-animation-verifier`, retensi 7), dicek lebih dulu. `strip_hcl_comments` sadar string (jangan kembali ke regex `//` biasa). Batas biaya: tambahan AWS US$5 per bulan atau lebih tidak boleh di-merge tanpa persetujuan pengguna (baris `Total tambahan AWS per bulan: US$...` di `07-cost-guardrails.md` dijaga `test-checkers.py`; baris persetujuan ditulis pengguna, bukan agen).

**CI/CD baru.** `ci.yml`: job `verifier` (`ci/verifier`: `npm ci`, `npm run lint`, `npx tsc --noEmit`, `npm run typecheck`, `npx vitest run` termasuk korpus, `shellcheck`, build image `linux/amd64` tanpa provenance dan SBOM, lalu `scripts/ci/verifier-rie-check.sh`) dan job `contracts` (`ci/contracts`: `scripts/sync-animation-contract.py --check` dan `scripts/ci/check-animation-versions.py`). `release-verifier.yml` (environment `production-release`, OIDC) membangun dan mendorong image ke ECR, memperbarui fungsi, memanggil satu fixture bagus dan satu buruk lewat `scripts/ci/verifier-release.sh`, lalu menulis tag ke SSM `/lore/prod/verifier/release/image_tag`; gagal berarti kembali ke tag sebelumnya. Workflow ini terpicu push ke `main` yang mengubah `animation-verifier/**`, jadi merge PR kode pertama sudah memicunya dan run itu merah sampai bootstrap, apply PR infra pertama, dan lockfile verifier ada. `release-web.yml` meneruskan `NEXT_PUBLIC_ANIMATIONS=${{ vars.NEXT_PUBLIC_ANIMATIONS || 'off' }}` sebagai build arg dan juga terpicu oleh `frontend/sandbox-runtime/**` dan `frontend/scripts/**`.

**Langkah manual (bukan agen):**
1. Bootstrap admin (`./infra/bootstrap/bootstrap.sh`, idempoten) setelah meninjau perubahan di `infra/bootstrap/policies/*.json`, lalu dua `aws iam simulate-principal-policy` (log group verifier `allowed`, log group lain `explicitDeny`). Selesai sebelum PR infra di-merge.
2. Tambahkan `ci/verifier` dan `ci/contracts` ke required checks ruleset `protection-main`. **Menunggu persetujuan pengguna.**
3. Tiga PR infra berurutan: (1) `animation_verifier_image_tag = ""` dan `animation_enabled = false` (24 resource baru, satu update in-place `metadata_options`, tanpa delete atau replace), (2) tag `sha-xxxxxxx` (menambah Lambda saja), (3) `animation_enabled = true` (satu update parameter SSM; tidak boleh ada perubahan `deploy/**`).
4. Rilis image verifier pertama, rilis api dan web dengan kedua flag mati, ukur memori api (ambang 600 MiB), jalankan `scripts/verify/animation-smoke.py`, daftar periksa browser Chromium dan Firefox, lalu variabel repositori `NEXT_PUBLIC_ANIMATIONS=on` dan `release-web` ulang. Flag_Web `on` dilarang bila smoke gagal atau RSS lebih dari 600 MiB.
5. Perintah `aws`, `gh workflow run`, `gh variable set`, dan `bootstrap.sh` dijalankan manusia. Pembuktian perilaku AWS yang belum terbukti (penulisan bersyarat S3 `If-None-Match`, 404 bukan 403 pada objek yang tidak ada, kredensial `boto3` di container) tetap `[belum diverifikasi]` sampai operator menjalankannya.
6. Ukuran `infra/bootstrap/policies/lore-gh-apply-policy.json` sudah 5529 dari batas 6144 karakter tanpa spasi putih: pernyataan baru berikutnya berarti memindahkan pernyataan animasi ke managed policy kedua.
